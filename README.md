# Bubble 算法动态演示与边播边讲 (Bubble Animation & Narration)

一个具有**自动动态动画**和**实时同步语音与文本解说（边演示边说明）**的演示项目，支持手机端与桌面端自适应浏览。

## 🌟 核心特性
- **两大气泡机制演示**：
  1. **冒泡排序 (Bubble Sort)**：数值扫描、相邻比对、动态对调、沉底就位与提前退出优化。
  2. **缓存冒泡 (Bubble Cache)**：微前端/组件树元数据（Tags、Context、TTL）自底向上冒泡汇总与局部精准失效机制。
- **边演示边讲解**：
  - 自动播放动画，每个比对和交换动作实时联动解说卡片。
  - 支持 **Web Speech API 语音朗读**（支持一键开闭）。
- **交互控制**：支持单步前进、单步后退、速率调节（0.5x / 1.0x / 2.0x）、重新播放。
- **移动端优化**：专为 iPhone 触摸操作优化，支持触屏缩放与滑动。

## 🚀 启动与运行

直接运行启动脚本即可：
```bash
./start.sh
# 或指定端口（默认 8080）
./start.sh 8888
```

## 📱 访问方式
- **本地浏览器**：`http://127.0.0.1:8080`
- **同一 Wi-Fi 局域网**：`http://<局域网IP>:8080`
- **Tailscale 远程网络**：`http://<Tailscale_IP>:8080`（如 `http://100.103.74.48:8080`）
